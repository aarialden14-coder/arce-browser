# Arce

A fast, good-looking browser for Mac, Windows and Linux: vertical tabs, uBlock ad blocking, a privacy and security report, Arce AI, reader mode, page translation, link previews, pop-out videos, live wallpapers, Arce Chat and Game Mode.

**Website: [aarialden14-coder.github.io/arce-browser](https://aarialden14-coder.github.io/arce-browser/)**

## Download

**[Download Arce for Mac](https://github.com/aarialden14-coder/arce-browser/releases/latest/download/Arce-Mac.zip)** — unzip it and drag **Arce** into your Applications folder. The first time, right-click Arce and choose **Open**. Works on Apple Silicon and Intel Macs running macOS 12 or newer.

**[Download Arce for Windows](https://github.com/aarialden14-coder/arce-browser/releases/latest/download/Arce-Setup.exe)** — run the installer, no admin needed.

**Download Arce for Linux:** **[.deb for Ubuntu, Debian, Mint and Pop!_OS](https://github.com/aarialden14-coder/arce-browser/releases/latest/download/Arce-Linux.deb)** (open it to install) or **[AppImage for any distro](https://github.com/aarialden14-coder/arce-browser/releases/latest/download/Arce-Linux.AppImage)** (make it executable, then run it). 64-bit only.

After that, Arce updates itself: when a new version is out, an **Update** button appears in the sidebar.
